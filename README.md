# PyClimaExplorer 🌍
**Technex '26 - IIT BHU Hackathon**

## Overview
PyClimaExplorer is a service which provides 3D representation of climate parameters like temperature, pressure and precipitation.

## Tech Stack
- **Frontend:** Streamlit
- **Data:** Xarray, Pandas
- **Maps:** Plotly

## How to Run
1. Create venv: `python -m venv venv`
2. Activate venv: `.\venv\Scripts\activate`
3. Install: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`
